Demo 版 · port 5000-5004

Demo 版是什么

这是测试先行版，新功能和测试都在这里开发。代码永远是最新的，日常开发、调试、添加新功能都在这个版本。

启动

  • 双击 start_all.bat 一键启动全部 5 个服务
  • 或单独启动子应用：application\xxx\start_xxx.bat

端口

  • Portal → 5000 · 域名抓取 → 5001 · 测试报告 → 5002
  • 配置生成 → 5003 · 配置梳理 → 5004

侧栏下载按钮

左侧栏底部的「下载完整应用」按钮，可以下载 dist/ 中最新的打包 zip。这就是客户拿到的交付版。

发布交付版

  1. 在 demo 版完成所有功能开发和测试
  2. git checkout release && git merge main 同步到交付分支
  3. 运行 py -3 tools/build_release.py --version v1.0.0 --mirror-url http://外部IP:6000/api/update/manifest
  4. 把生成的 zip 部署到交付版服务器 dist/ 目录
  5. 客户端的交付版自动检测到新版本并提示升级

测试

全量测试（不含浏览器 E2E）：

cd application\test && py -3 -m pytest --deselect all_in_one/test_e2e_playwright.py

预期 50 passed。

交付版怎么用

交付版在 release 分支，端口 6000-6004。客户通过外部 IP 访问更新。切换到 release 分支即可查看：

git checkout release
