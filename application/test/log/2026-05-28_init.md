# 2026-05-28  application/test 仓库初始化

`application/test/` 目录今日由本次整合任务首次建立，包含全部 Python 测试。

## 子目录
- `all_in_one/`     — 从 `application/all_in_one - cc/test/` 整体迁移过来，17 个 .py + `test_er5/` 子目录。
- `portal/`         — 新增烟雾测试 1 个。
- `test_report/`    — 新增烟雾测试 1 个。
- `domain_capture/` — 新增烟雾测试 1 个。
- `config_analyzer/` — 新增烟雾测试 1 个。

## 共用模块
- `_smoke_helpers.py`     — subprocess + 端口探测 + http.get + SmokeServer ctx manager。
- `all_in_one/_bootstrap.py` — 为 all_in_one 测试集中注入 `web/`、`src/` 到 `sys.path`，并设置 `TEST_MODE=1`。
- `all_in_one/conftest.py` — pytest session 级 Flask server + `page` fixture（自动跳转首页）。

## 跑测试

```powershell
# 全套 pytest（不含 Playwright E2E，需要顺序执行）
py -3 -m pytest --deselect all_in_one/test_e2e_playwright.py

# Playwright E2E (standalone)
py -3 all_in_one\test_e2e_playwright.py --quick

# 仅某个应用
py -3 -m pytest portal
py -3 -m pytest all_in_one\test_hostname_all.py
```

## 已知约束
- Playwright E2E 用例 (`test_e2e_playwright.py` 内的 17 个 `test_*`) 在 pytest 单独跑某条 OK，但全套连跑因测试之间有状态依赖（保存模板、隔离测试需要顺序），目前推荐用 standalone `--quick` / 全量入口。
- 端口占用 (5000 / 5739 / 5740 / 5741 / 5742) 是测试串行执行的前提。被占时各 fixture 会主动报错而不是隐式复用。
