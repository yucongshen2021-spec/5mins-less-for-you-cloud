### Task: 多并发改造（gunicorn 多 worker + 异步日志，8000 端口验证通过）

all_in_one 配置生成应用原强制 `threaded=False`（单线程），根因是用 `exec()` 加载桌面版业务模块并创建共享 `tk.Tk()` + `_EMBEDDED_NS` 全局 namespace，每请求原地改共享 ns（`_inject_network_to_module` 写 `DEFAULT_*` globals、`_set_closure_vars` 改 tkinter 闭包 cell），并发下会互相覆盖导致配置串号。tkinter 非线程安全，不能简单改 `threaded=True`。

**方案：gunicorn 多 worker 进程隔离**。每个 worker 独立进程 = 独立 Tk 实例 + 独立 `_EMBEDDED_NS`，worker 内仍单线程，worker 间天然并发。不改动任何业务模块代码。8 个 worker（4c4g 可支持，每 worker ~100MB）。

#### 改动文件

**新增 `application/all_in_one - cc/web/wsgi.py`** — gunicorn 入口
- 从 `app.py` import `app`，暴露 `application = app`
- import `init_worker`、`check_and_reload_runtime` 供 gunicorn 钩子调用

**新增 `application/all_in_one - cc/web/gunicorn_conf.py`** — gunicorn 配置
- `workers=8`（`GUNICORN_WORKERS` 环境变量可覆盖）、`worker_class=sync`、`timeout=120`
- `max_requests=200`（防 tkinter/内存累积泄漏）、`preload_app=False`（Tk 不能跨 fork）
- `post_fork(server, worker)` 钩子调 `wsgi.init_worker()` 初始化业务模块

**改 `application/all_in_one - cc/web/app.py`**
- 提取 `init_worker()` 公开函数：`_preload_all_modules` + `_snapshot_factory_defaults` + `_load_init_defaults` + `_load_workspace_templates`（原 `__main__` 逻辑，供 wsgi post_fork 和裸机模式共用）
- 新增多 worker 状态同步机制：`_touch_reload_stamp()` / `check_and_reload_runtime()`
  - sentinel 文件 `data/.reload_stamp`，模板/默认值保存后 touch
  - 每个 generate 请求开始前 `check_and_reload_runtime()` 检查 mtime，变化则重载 init defaults + workspace templates 到当前 worker 的 `_EMBEDDED_NS`
  - 解决多 worker 下"worker A 保存模板 → 其他 worker 内存 ns 不同步"问题
- 6 个 generate 路由（epoch_fastip/epoch_fastip5/usg_fastip/epoch_mpls/ar_sdwan/ar_traditional）入口插入 `check_and_reload_runtime()`
- `api_template_save` / `api_init_defaults_save` 保存后调 `_touch_reload_stamp()`
- `__main__` 改用 `init_worker()`，裸机 `python app.py 5003` 仍可用

**改 `application/portal/proxy.py`** — 异步日志
- 新增 `deque` 队列 + 后台守护线程 `stats-log-writer` 批量写 SQLite（每 0.5s 或满 50 条 flush）
- `_try_log` 改为在请求线程内采集所有 request 上下文数据（脱离 flask request 依赖），组装 dict 后 `_enqueue_log`（非阻塞）
- 高并发下 portal 工作线程不再被 SQLite 写入阻塞

**改 `docker/supervisord.conf`** — all_in_one 改 gunicorn 启动
- `command=/usr/local/bin/gunicorn -c ".../gunicorn_conf.py" wsgi:application`
- `directory=.../all_in_one - cc/web`，`GUNICORN_WORKERS=8`

**改 `requirements.txt`** — 加 `gunicorn>=22.0`
