- 说明: 修复 cascade menu 场景选择消失的 bug。
  根因: tpl-col1 同时作为根容器且有 cascade-col CSS class，
  _renderCascadeCol 在它内部创建 level-1 ul.cascade-col，
  CSS .cascade-col .cascade-col {display:none} 将 level-1 永久隐藏，
  且 hover 规则 .cascade-col li:hover>.cascade-col 只匹配 li 的直接子元素，
  level-1 ul 是 tpl-col1 的直接子元素(不在 li 内)，永无法被 hover 触发。
  修复: 从 tpl-col1 移除 cascade-col class，改为普通 ul 容器。
  教训: 此 bug 从 commit fc214c0 引入时就存在，但 API 测试
  (test_template_editor_e2e.py 用 urllib 直调后端) 不测 UI 渲染，
  导致测试全过但用户看不到场景选择。
