### Task 4: Single-Buffer Pipeline (replace_single_field + generate_speedtest_image)

- 文件: `application/自动做测试报告 - cc/src/speedtest_render.py`
- 说明: 添加核心渲染管道——单一图像缓冲区（BGR np.ndarray）贯穿全流程：
  - 常量: `UPSCALE=8`, `INPAINT_RADIUS=3`, `MASK_THRESHOLD=10`
  - `replace_single_field(cv_bgr, field, new_text, protection_mask, weight)` — 单字段原地替换：
    1. 从 OCR bbox 提取字符掩码（边界采样中值背景 + 阈值）
    2. 减去保护掩码（静态元素）
    3. TELEA 修复仅字符像素
    4. 二分查找匹配字体（find_exact_font_size）
    5. 8 倍渲染于透明 RGBA 画布 → Lanczos 缩小至 1 倍
    6. compute_baseline_y 基线对齐放置
    7. Alpha 合成直接写入 cv_bgr（BGR 通道旋转）
  - `generate_speedtest_image(template_path, output_path, ...)` — 完整管道编排器：
    OCR 检测 → 分类 → 保护 → 修复 → 渲染 → 纹理（占位噪声）→ 输出
  - Unicode 路径修复: 使用 `np.fromfile + cv2.imdecode`（读取）和 `cv2.imencode + write_bytes`（写入），因为 cv2.imread/imwrite 不支持 CJK 路径
- 测试结果: (326, 723, 3), Has content: True — 已通过
