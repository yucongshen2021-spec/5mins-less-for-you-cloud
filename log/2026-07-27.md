- 文件: `application/fastip_report/data/fastip-auto-test-report.zip`（新增）—— 由 `~/fastip-auto-test-report` 打包，排除 .git/__pycache__/test_*。

### wine 跨平台打出真 Windows exe，替换源码包为 exe 版

之前因仓库无 exe、无 release、本机无 wine 判"无法打 exe"，交付了源码包 zip。复核发现 wine **在 apt 源里就有**（candidate 9.0，走腾讯云镜像，上次 grep 报错误判），故实际用 wine + Windows Python 跨平台打出真 exe，目标「下载桌面版 windows(exe)」达成。

- 装 wine: `apt install wine64`（v9.0），初始化 `WINEPREFIX=/opt/fivemins/.wine64 WINEARCH=win64 wineboot --init`（跳过 mono/gecko）。
- Windows Python: 从 python-build-standalone 下完整 `cpython-3.13.13+20260510-x86_64-pc-windows-msvc-install_only_stripped.tar.gz`（含 tkinter `_tkinter.pyd`+`tcl86t.dll`/`tk86t.dll`、pip）。验证 `wine python.exe --version`→3.13.13、`import tkinter`→TkVersion 8.6。
- 装依赖: `wine python -m pip install` paramiko/python-docx/Pillow/pyinstaller（全是预编译 Windows wheel，无需编译）。ensurepip 报 `CopyFile2 unimplemented` 但 pip 仍可用（26.1.1）。
- 打 make_report.exe（引擎，onefile）: `PyInstaller --onefile make_report.py` → 25.7MB，PE32+(console)。`wine make_report.exe --help` exit 0（paramiko/docx/PIL 全加载正常）。
- 打 report_gui.exe（GUI，onefile --windowed）: → 10.4MB，PE32+(GUI)。
- GUI 冲烟: 装 xvfb（本机已有），`timeout 25 xvfb-run -a wine report_gui.exe` → 进程跑到 25s 被 timeout 杀（exit 143，无 traceback 无秒退）= tkinter 根窗口创建、进入 mainloop，GUI 可跑。
- 组装 exe 版 zip（按 README 布局）: report_gui.exe + src/make_report.exe + script/FASTIP-测试报告.docx + 使用说明/应用能力说明 + ce_credentials.example.json，共 34.1 MB。替换 `application/fastip_report/data/fastip-auto-test-report.zip`。
- 页面文案 46KB源码→34MB exe版: cta hint「解压后双击 report_gui.exe 即用」、包内文件改列 report_gui.exe/src/make_report.exe/模板/说明、流程 01 改「解压 ZIP...exe 与 script/src 同级」、guest 文案改「无需安装 Python」。
- 验证（8000 全过）:
  - 页面文案为 exe 版（约 34 MB / report_gui.exe）。
  - 访客 `/api/download` → 403。
  - 登录下载 → 200，size=35743467 (34.1MB)，Zip archive。解压后 `file` 两个 exe: report_gui.exe=PE32+(GUI)、src/make_report.exe=PE32+(console)。
  - 浏览器 iframe 内点下载按钮 → 触发 `FASTIP-测试报告工具.zip` 下载，页面不跳走。
  - 下载统计记录「下载·FASTIP测试报告」yucs，resp_size=35743467（exe 版，区别于旧的 46921 源码版）。
- 结论: 「下载桌面版 windows」核心要求达成——下载的是 PyInstaller 打的、wine/xvfb 验证可跑的真 Windows exe（GUI+引擎），无需装 Python。生产 5000 待用户确认后部署。
